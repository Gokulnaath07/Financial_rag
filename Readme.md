1. What problem does this API solve?

This API reduces the time and effort required to manually search and verify information in complex financial documents by allowing users to ask questions and receive citation-backed answers directly from the source files.

2. Who is the user?

Finance analysts, HR teams, auditors, and other professionals who work with financial documents such as tax forms, pay stubs, and related records.

3. What input does it accept?

Unstructured documents (PDF, TXT) and natural-language questions.

4. What output does it return?

Answers grounded in the uploaded documents, along with citations indicating the exact sections or pages where the information was found.

5. What does a “correct answer” mean?

An answer is considered correct only if it is fully supported by the retrieved document content and includes verifiable citations, with no fabricated or inferred information.
